AGENTE QA - SIGUIENTE PASO SEGURO

Flujo:
Test Plan -> Suite -> Test Cases.
Si la Suite no tiene Test Cases:
1. Seleccionar un CP ya generado por el Agente QA.
2. Preparar una propuesta para esa Suite.
3. Revisar la vista previa.

IMPORTANTE:

No se agregaron operaciones POST, PATCH o DELETE.
